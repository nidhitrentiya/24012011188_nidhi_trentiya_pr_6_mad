# 📱 MAD Practical 6 – Android Application

## 📌 Project Overview

This project is developed as part of the **Mobile Application Development (MAD)** practical coursework. It focuses on learning Android application development using Android Studio and implementing mobile application concepts through practical programming.

The project provides hands-on experience with Android project structure, user interface development, application configuration, and execution.

## ✨ Features

- Android application development using Android Studio.
- Organized project structure.
- User interface implementation.
- Gradle-based project configuration.
- Application building and execution.
- Scope for future improvements and additional functionality.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Android emulator or physical Android device

### Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/nidhitrentiya/24012011188_nidhi_trentiya_pr_6_mad.git
```

**2. Open the project**

Open Android Studio and select the cloned project folder.

**3. Sync Gradle**

Allow Android Studio to synchronize the Gradle files and download the required dependencies.

**4. Run the application**

Select an emulator or connect your Android device, then click the **Run ▶** button.
